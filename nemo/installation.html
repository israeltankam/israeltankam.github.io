Installation

Python requirements

NEMO-PCN supports Python 3.10 or newer and uses NumPy, SciPy, Pandas and Numba. Matplotlib and Plotly are optional visual dependencies. On a computer without network access, the necessary wheels must be installed in advance.

Install from a local folder

After extracting the distribution archive, open a terminal in its root:

python -m venv .venv
# Windows
.venv\Scripts\python -m pip install --upgrade pip
.venv\Scripts\python -m pip install -e "./nemo-pcn[viz]"
# Linux or macOS
# .venv/bin/python -m pip install -e './nemo-pcn[viz]'

An editable installation allows changes to the package source to take effect without a new wheel build. After packaging on PyPI, install with:

python -m pip install "nemo-pcn[viz]"

Check the environment

import nemo_pcn as nemo
print(nemo.__version__)
assert nemo.hardy_weinberg(0.2).sum() == 1

Run the included suite:

python -m pip install pytest
python -m pytest nemo-pcn/tests -q

Numba compilation

A Numba kernel compiles on first execution. The compilation takes longer than later calls and is not included in comparisons of steady-state simulation speed. Thousands of trajectories can be simulated efficiently because replicates are parallelised. Runtime still increases with larger populations and longer calendars.

Build a wheel

python -m pip install build twine
python -m build nemo-pcn
python -m twine check nemo-pcn/dist/*

Always publish from a clean version-controlled release and verify installation in a fresh virtual environment.
