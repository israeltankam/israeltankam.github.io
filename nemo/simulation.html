Stochastic and deterministic simulation

Core API

nemo.run_simulation(parameters, schedule, initial_density=20,
    virulence_frequency=.2, genotype_initial=None,
    area_m2=1., n_replicates=1000, threshold=1., seed=42)

Each replicate uses a separately seeded random stream. Numba parallelises independent replicates while preserving the serial order of annual transitions within a replicate.

The simulation result contains: density, allele, homozygote, effective_size, females, males, schedule, parameters, initial_density, area_m2, threshold and seed.

Arrays use replicate × year dimensions. Breeder-related arrays have one value per crop-year transition; density and frequencies include year 0.

Deterministic mean-field reference

reference = nemo.deterministic(parameters, schedule,
                               initial_density=20,
                               virulence_frequency=.2)

At large population size, stochastic density trajectories concentrate around the mean-field recursion under regularity assumptions. This does not imply that the deterministic curve is exactly the expected stochastic density in a finite population.

Large versus small reproductive populations

When the expected number of reproductive aa females is large, the 95% band can be visually much narrower than the plotted ordinate range. For rare virulence and a small mating focus, female recruitment can fail in the first resistant crop, producing extinction even when a deterministic trajectory remains positive.

Extracting and plotting distributions

r = nemo.run_simulation(area_m2=.0054, n_replicates=2000, seed=9)
print(r.summary('density')[['year','p025','median','p975']])

from nemo_pcn.viz import plot_trajectories
fig = plot_trajectories(r, 'density', show_replicates=20)

Use result.raw('density') for replicate-level data and result.export(...,raw=True) to save exact underlying trajectories. Very large arrays may consume substantial memory.

Reproducibility and computational limits

Record the model variant, genotype initialization, input units, calendar, soil scale and seed. The integer-valued algorithm can become costly for very large population sizes. A probability close to one in a finite ensemble is not a mathematical certainty.
