Figures and data export

Trajectories and uncertainty

from nemo_pcn.viz import plot_trajectories,save_figure
fig = plot_trajectories(result,'density',show_replicates=20)
save_figure(fig,'density.pdf')

The curve is the median across independent populations. The band uses the 2.5% and 97.5% pointwise quantiles. In an abundant population, it may be too narrow to see without numeric quantiles, and should not be exaggerated for appearance.

Agricultural endpoints

from nemo_pcn.viz import plot_outcomes
fig=plot_outcomes(result)
save_figure(fig,'outcomes.png')

Compare rotations

comparison=nemo.compare_strategies(
    cycles=['RN','RNN','RNNN','RNNNN'],
    biocontrol=[.2,.4,.6,.8],virulence=[.2],years=50)
from nemo_pcn.viz import plot_strategy_heatmap
fig=plot_strategy_heatmap(comparison,metric='p_extinct',year=50,q0=.2)
save_figure(fig,'strategy_heatmap.pdf')

Export all numerical outputs

result.export('outputs/scenario_B',raw=True)

The output folder includes one CSV per summary variable, optional replicate-level CSVs, outcomes.csv, annual_schedule.csv and a JSON file containing the full scenario. Each file retains the measurement time and variable names. PDF figures are vector-based and PNG figures support presentation and reports.

Interpretation checklist

Before reporting results, specify units, parameterisation, soil area, random seed, genotype initialization, Monte Carlo sample size, threshold and complete calendar. State whether an interval represents variation among populations or uncertainty in estimated mean/probability.
