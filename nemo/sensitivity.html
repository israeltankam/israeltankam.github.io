Parameter sensitivity and robust decisions

Global sensitivity

nemo_pcn.sensitivity_screen() implements a Saltelli/Jansen design over independent continuous parameter ranges. It estimates first-order and total-order sensitivity indices for final density and extinction probability.

sens = nemo.sensitivity_screen(
    bounds={'e':(300,500),'s':(.15,.35),
            'alpha':(.08,.30),'b':(.20,.90),
            'q0':(.05,.80)},
    cycles='RNN',years=35,n_base=128,
    n_replicates=500,seed=42)

The expected response at each parameter vector is estimated by Monte Carlo. The final indices are therefore affected by stochastic response noise. Evaluate convergence in both the Sobol base size and the replications per design; small negative or greater-than-one finite-sample estimates should not be silently truncated or treated as proven effects.

Robustness across parameterisations

models = {
 'establishment': nemo.ESTABLISHMENT_REFERENCE,
 'fecundity': nemo.ORIGINAL_FECUNDITY,
}
compare = nemo.calibration_robustness(
    models,cycle='RNNNN',horizon=50,
    q0=.20,replications=1000)

Comparing two structural models fitted to different data contexts is an examination of model uncertainty; it is not a fair predictive contest unless each is refitted to comparable observations and evaluated on independent data.

Local population subdivision

patches = nemo.compare_isolated_patches(
    area_m2=.05,patch_counts=[1,2,4,8],
    schedule=nemo.Schedule('RNN',50),
    n_replicates=500)

Each patch is closed and internally panmictic. This diagnostic does not model dispersal, migration or the actual geography of a potato field. A connected spatial model would require explicit movement parameters and spatial validation.

Decision horizons

It is generally useful to evaluate 5, 10, 20, 30 and 50 years on the same simulation ensemble. Longer extinction tails may be relevant to mathematical extinction theory but need not dominate agricultural decision making. Report crop exposure, initial infestation, virulence and parameter uncertainty alongside predicted probabilities.
