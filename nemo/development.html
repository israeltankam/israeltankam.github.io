Running tests

python -m pip install -e './nemo-pcn[dev,viz]'
python -m pytest nemo-pcn/tests -q

The tests verify genotype combination probabilities, calendars, reproducible independent random draws, extinction as an absorbing state, agreement with a deterministic large-population benchmark and parameter-fitting interfaces. A passing software test does not establish biological validity outside the calibration context.

Scientific checks before publication

  1. Reproduce published formulae and use dimensions consistently.
  2. Compare stochastic medians with deterministic trajectories in the large-population regime.
  3. Quantify prediction intervals in small reproductive populations and evaluate extinction events.
  4. Retain extinct replicates when estimating survival probabilities, but exclude undefined allele frequencies from frequency summaries.
  5. Check fitted residuals, parameter identifiability and alternative regulation hypotheses.
  6. Run sensitivity convergence diagnostics and independent-parameter seed checks.
  7. Validate management predictions on independent experimental or field measurements when available.

Versioning and publication

Release tags should record changes in model equations, fit assumptions, random generator behaviour and export schema. An apparent parameter improvement from one experimental data set should not silently replace a reference parameter set in an existing reproducible study.
