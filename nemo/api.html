API reference

The public interfaces are available from nemo_pcn:

• `Parameters` — demographic and control parameters

• `Scenario` — crop sequence, time horizon, genotype initialization, local focus area, yearly biocontrol

• `simulate()` — Numba-accelerated stochastic replicate trajectories

• `deterministic()` — deterministic expectation-limit reference

• `compare_strategies()` — repeated crop schedules and efficacy gradients

• `fit_two_stage()` — cyst recruitment and eggs per cyst

• `fit_density()` — paired initial/final density data

• `fit_counts()` — Poisson or negative-binomial count data

• `fit_hatching()` and `fit_virulence()` — binomial diagnostic data

• `plot_trajectories()`, `plot_virulence()` and `plot_management()` — exportable figures

See the source package docstrings and Python typing for complete arguments.
