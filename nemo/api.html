Public API reference

This page indexes the main functions. Signatures may gain optional parameters with later releases; use Python introspection for the installed version.

Biological objects

  • Parameters(e, s, mu, h, alpha, m, b, regulation): validated biological configuration.
  • Schedule(cycle, years, biocontrol): annual crop programme and annual intervention efficacy.
  • hardy_weinberg(q): three initial genotype proportions.
  • genotype_proportions(values): validated custom proportions.
  • male_genetic_combinations(males): three original maternal genotype-specific combination vectors.
  • offspring_genotypes(females, males): expected offspring counts per genotype before survival and fecundity scaling.
  • virulence_equilibrium(m): stable interior composition when m < 0.5.
  • soil_mass(area_m2, depth_m, bulk_density_g_cm3): convert focus area to simulated soil mass.
  • reproduction_metrics(parameters, nonhost_years): reproduction multipliers and equilibrium diagnostics.
  • treatment_timing(cycle, years, efficacy, mode): scheduled intervention timing.

Simulation

  • run_simulation(...) → SimulationResult, including summary, raw, outcomes and export methods.
  • deterministic(...) → Pandas table of mean-field genotype densities and frequencies.
  • simulate_neutral_marker(...) → NeutralMarkerResult with selected and neutral allele frequencies.
  • selected_allele_variance_components(...) → conditional offspring allele-copy variance terms.
  • compare_stochasticity_mechanisms(...) → four explicitly labelled counterfactual stochastic processes.
  • summarize_stochasticity_comparison(...) → annual table of outcomes from these processes.
  • compare_isolated_patches(...) → no-migration patch subdivision diagnostic.

Strategy and sensitivity

  • compare_strategies(...): cross-product of crop programmes, annual efficacy values and initial allele frequencies.
  • female_recruitment_risk(...): expected initial female recruitment and exact no-female probability under genotype sampling assumptions.
  • fixation_window(...): comparison of polymorphic and fixed-virulence low-density multipliers.
  • sensitivity_screen(...): first-order and total-order Jansen indices.
  • calibration_robustness(...): compare model parameterisations under one specified programme.
  • uncertainty_envelope(result,variable): selected quantiles and valid fractions.

Parameter fitting

  • fit_recruitment_fecundity(data, ...,fecundity='constant',bootstrap=0)
  • fit_fecundity(data,curve='reciprocal')
  • fit_hatching(data,model='constant')
  • fit_egg_survival(data)
  • fit_population_trajectory(data,parameters,cycle,fit)
  • fit_allele_trajectory(data,parameters,cycle,fit)
  • fit_reproduction_factor(data,parameters,fit)

Visualization

  • nemo_pcn.viz.plot_trajectories(result,variable,...)
  • nemo_pcn.viz.plot_outcomes(result,...)
  • nemo_pcn.viz.plot_strategy_heatmap(frame,metric,year,q0,...)
  • nemo_pcn.viz.plot_fit(fit)
  • nemo_pcn.viz.save_figure(fig,filename,dpi)

All visualization functions return regular Matplotlib figures. Graphics are optional and the simulation package can be used without a graphical interface.
