Package and documentation publishing

Build the Python distribution

python -m pip install build twine
python -m build nemo-pcn
python -m twine check nemo-pcn/dist/*

Use TestPyPI to validate the distribution and dependencies before publishing on PyPI. Never commit publishing tokens. Stable publication can be automated using PyPI Trusted Publishing tied to an authorised GitHub workflow.

Publish documentation on GitHub Pages

Copy the self-contained nemo/ directory to the root of the repository israeltankam.github.io beside the existing cropmix/ directory. Commit and push to the GitHub Pages publishing branch. The relative paths in the site permit direct access at https://israeltankam.github.io/nemo/.

The package also contains Markdown sources under docs/, plus mkdocs.yml for teams that prefer maintaining the documentation with Material for MkDocs.

python -m pip install 'mkdocs-material>=9'
cd nemo-pcn
mkdocs serve
mkdocs build

The output of MkDocs can be deployed instead of the prebuilt static files. Choose one canonical source for ongoing edits to avoid documentation divergence.

Release checklist

  • All tests pass on an explicitly supported Python version.
  • Source and binary distributions pass twine check.
  • Reference parameter values and any imported calibration data carry provenance.
  • The published documentation corresponds to the tagged code release.
  • Public examples produce their described outcomes without depending on unpublished files.
