Installation and publishing

Local installation

python -m venv .venv
# Windows: .venv\Scripts\activate
python -m pip install -e ".[app,dev,docs]"
pytest -q
streamlit run ../nemo-streamlit/app.py

Publish package to PyPI

The maintainer must create and configure an account and trusted publishing, or an appropriately scoped API token.

python -m build
python -m twine check dist/*
python -m twine upload dist/*

Publish documentation

mkdocs build

The generated site/ is suitable for deployment to GitHub Pages. For the existing israeltankam.github.io repository, copy the contents of site/ into the nemo/ folder and commit the change. Do not overwrite the cropmix/ folder. If using a standalone source repository instead, mkdocs gh-deploy publishes into its GitHub Pages branch and may use a different URL depending on hosting configuration.
