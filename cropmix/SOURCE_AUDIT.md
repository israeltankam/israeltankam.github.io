# Documentation source audit

This HTML documentation targets the exact Cropmix **0.2.1** source snapshot embedded in:

`Final_robust_complete_revised_2026-08-24.zip`

The API page was generated by Python introspection of that source tree. It covers:

- every symbol in `cropmix.__all__`;
- every symbol in `cropmix.epipvr.__all__`;
- public methods/properties on those classes;
- `cropmix.metrics.pairwise_mixing_metrics`;
- `cropmix.kernels.symmetric_sinkhorn`;
- CLI and public exception classes;
- all non-underscore publication-backend functions/classes used by the manuscript workflow.

The source test directory was executed during the documentation build:

`17 passed, 1 DeprecationWarning` (the warning is the intentional `calibrate_kernel()` compatibility alias).

The website deliberately corrects several manuscript/notebook-level compatibility descriptions where they differ from the frozen package source. In particular:

- core `simulate_mixture()` has **no** `engine`/`backend` keyword in this snapshot;
- `VectorInoculum` uses `infectious_fraction` and `origin_weights`;
- `VectorInoculum.none()` is the source API for virus-free vectors;
- the large 100x100 structured workflow is in `cropmix.publication_backend` rather than an automatic core-engine selector.
