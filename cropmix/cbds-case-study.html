CBSD worked example

See how the cassava analysis instantiates Cropmix while keeping study-specific 50:50 geometry, movement, biology and scenario assumptions separate from the reusable package.

Purpose

The CBSD workflow is a worked parameterisation and manuscript analysis, not the definition of Cropmix. It uses two contrasted phenotypes and a controlled 50:50 square design to isolate arrangement effects, while the core package supports different compositions, more SPT varieties and arbitrary finite geometries.

Core biological objects

import cropmix as cm

SUSC = cm.Variety(
    "SUSC",
    cm.HostTransmission(15.31, 1.34),
    cm.PlantParameters(1/30, 0.0),
    cm.YieldParameters(31.0, 3.1, "t/ha"),
)
RES = cm.Variety(
    "RES",
    cm.HostTransmission(4.84, 0.42),
    cm.PlantParameters(1/30, 0.0),
    cm.YieldParameters(25.0, 2.1, "t/ha"),
)
SYSTEM = cm.CropMixSystem(
    (SUSC, RES),
    cm.VectorParameters(0.19, 0.45),
    cm.PathogenParameters(19.37, "SPT"),
    cm.ExponentialKernel(2.625),
)

Movement and harvest choices

The primary Cropmix exponential scale is a=2.625 m, translating a published two-dimensional exponential mean distance of 5.25 m; the biological sensitivity interval is 0.5–5.75 m. The primary season is 300 days and the prespecified harvest-time sensitivity is 120, 180, 240, 300 and 360 days.

Controlled 100×100 study design

FIELD = cm.Field.rectangular(100,100,spacing=1.0)
DESIGN = cm.MixtureDesign.random(FIELD, {"SUSC":5000, "RES":5000}, seed=20260824)
SCENARIO = cm.Scenario(
    duration=300,
    vectors_per_plant=10,
    inoculum=cm.Inoculum.random(1),
    vector_inoculum=cm.VectorInoculum.none(),
)

At this scale, the manuscript does not use core dense simulate_mixture() for the full campaign; it uses the structured publication backend/cluster runner. The 10×10 quick notebook uses the same biology for fast exploration.

Case-study vector-pressure scenarios

Vector burdens m=1,5,10 are scenario values. Later exploratory analyses also crossed those values with initial infectious counts 1,5,10 to form nine labels such as LvLi and HvHi. Those labels belong to the analysis—not the package API.

Spatial descriptors

The 12 publication metrics were added to generalise what the canonical 50:50 arrangements teach us. Rather than carrying only layout names forward, the analysis asks which geometric features explain simulated incidence and yield across a larger exact-count arrangement ensemble.

What remains general in Cropmix

  • Field coordinates may be rectangular, masked, polygonal or directly surveyed.
  • Exact composition need not be 50:50.
  • The core SPT system can contain more than two varieties.
  • Plant introductions may be zero, random or fixed; vector infection can independently seed the epidemic.
  • Optimisation accepts any exact variety count vector and built-in/custom scalar objective.
Do not transfer CBSD numbers blindlyThe CBSD movement scale, transmission rates, vector burden and yields are pathosystem-specific inputs. Reparameterise them for other crops/pathogens rather than treating them as software defaults.
