Geometry & planting designs

Represent regular or irregular fields and create, import, export, plot and manipulate exact planting assignments without imposing a 50:50 or two-variety restriction.

Field: arbitrary 2-D planting coordinates

Field is the canonical geometry. It stores unique finite two-dimensional coordinates plus optional site IDs, a boundary, rectangular grid metadata and arbitrary metadata. Rectangles, masks and polygons are constructors around the same coordinate representation.

Field
Field(coordinates, site_ids=None, boundary=None, grid_shape=None, metadata={...})

Direct constructor. Coordinates must have shape (n_sites, 2), be finite and unique. If site IDs are omitted, string IDs "0", "1", … are created.

Field.rectangular
Field.rectangular(rows, columns, *, spacing=1.0, origin=(0.0, 0.0))

Create a complete rectangle. spacing may be one scalar or (sx, sy); grid_shape is stored so designs can be reshaped.

Field.from_coordinates
Field.from_coordinates(coordinates, *, site_ids=None, boundary=None, metadata=None)

Create a field from surveyed/custom coordinates; use this for irregular finite planting positions.

Field.from_mask
Field.from_mask(mask, *, spacing=1.0, origin=(0.0, 0.0))

Create sites at True cells of a 2-D Boolean mask. Site IDs are generated as r{row}c{col}.

Field.from_polygon
Field.from_polygon(boundary, *, spacing=1.0, origin=None)

Generate a regular lattice clipped to a polygon. Boundary points are included by the point-in-polygon logic.

Field.distance_matrix
field.distance_matrix()

Return the full pairwise Euclidean distance matrix.

Field.site_index
field.site_index(site_id)

Resolve a site ID to its integer index; raises KeyError for an unknown ID.

Field properties

PropertyMeaning
coordinatesRead-only (M,2) coordinate array.
n_sitesNumber of planting positions.
x, yCoordinate columns.
extent(xmin, xmax, ymin, ymax).
site_idsUnique string IDs, one per site.
boundaryOptional polygon vertex array.
grid_shapeSet for complete rectangles; otherwise generally None.
metadataUser/constructor metadata dictionary.

MixtureDesign: one variety label per site

MixtureDesign
MixtureDesign(field, assignment)

Create a design from an existing Field and exactly one non-empty variety label per site.

MixtureDesign.random
MixtureDesign.random(field, counts, *, seed=None)

Shuffle an exact multiset of variety labels. Counts must be non-negative and sum exactly to field.n_sites.

MixtureDesign.monoculture
MixtureDesign.monoculture(field, variety)

Fill every site with one variety.

MixtureDesign.from_grid
MixtureDesign.from_grid(grid, *, spacing=1.0)

Create a complete rectangular field and design from a 2-D array of labels.

MixtureDesign.from_dataframe
MixtureDesign.from_dataframe(dataframe, *, x="x", y="y", variety="variety", site_id="site_id")

Import x, y, variety and optionally site ID columns from pandas.

MixtureDesign.to_dataframe
design.to_dataframe()

Export site ID, x, y and variety columns.

MixtureDesign.as_grid
design.as_grid()

Reshape assignment into field.grid_shape. Only valid for complete rectangular fields.

MixtureDesign.variety_indices
design.variety_indices(variety)

Return integer indices carrying the requested variety.

MixtureDesign.swapped
design.swapped(first, second)

Return a new design with two labels exchanged; composition is preserved exactly.

MixtureDesign.plot
design.plot(ax=None, *, marker_size=80, legend=True)

Scatter plot of cultivar assignment; requires cropmix[viz].

Design properties

PropertyMeaning
n_sitesNumber of sites.

countsExact count dictionary.
proportionsCount divided by number of sites for each variety.
assignmentImmutable tuple of site labels.
fieldUnderlying Field.

Examples

# Irregular surveyed field
field = cm.Field.from_coordinates(
    [(0,0), (1.2,0.1), (2.4,0.0), (0.4,1.1), (1.8,1.3)],
    site_ids=["p1","p2","p3","p4","p5"],
)
design = cm.MixtureDesign(field, ("A","A","B","C","B"))

# Exact non-50:50 three-variety composition
field2 = cm.Field.rectangular(20, 20)
design2 = cm.MixtureDesign.random(
    field2,
    {"Elite":240, "Resistant":120, "Tolerant":40},
    seed=17,
)
print(design2.counts, design2.proportions)
Core generalityThe package core is not restricted to square fields, two varieties or 50:50 composition. The paper uses a controlled 50:50 two-variety design to isolate arrangement effects; the reusable core accepts arbitrary finite coordinates and exact compositions.
