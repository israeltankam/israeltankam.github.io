High-performance regular-grid backend

Specialised utilities for large binary square lattices and adaptive Monte Carlo simulation.

Scope#

cropmix.publication_backend is a specialised computational module for large, regular square lattices. It represents two varieties as a binary N×N grid and avoids the dense pairwise movement matrix used by the geometry-general simulator. Use this module when its square-grid and two-variety assumptions match the problem; use the core Field, MixtureDesign and simulate_mixture() API for arbitrary coordinates or more than two varieties.

Choose the backend by model structure The geometry-general simulator and the regular-grid backend implement different computational representations. Select the regular-grid backend only when its binary square-lattice assumptions are scientifically appropriate.
