Advanced & publication backend

Reference every public helper in the square-lattice publication backend, including structured kernels, adaptive ensembles, seed utilities and the 12 binary-grid metrics.

Scope

cropmix.publication_backend is included in the 0.2.0 package source for the manuscript’s large square-field analysis. It is not the geometry-general core API: the stochastic backend is a two-variety binary N×N implementation with cultivar codes 0/1 and dedicated SUSC/RES outputs.

StructuredKernel and preparation

StructuredKernel
StructuredKernel(N, scale, balance, displacement_dr, displacement_dc, displacement_cdf, mean_step_distance, max_row_error, iterations)

Matrix-free square-lattice kernel representation.

prepare_structured_kernel
prepare_structured_kernel(N, scale, *, tolerance=1e-8, max_iter=5000, damping=0.5)

FFT-based symmetric balancing for an open N×N unit-spaced lattice.

High-throughput SSA helpers

batch_publication_ssa
batch_publication_ssa(N, cultivar, balance, drs, dcs, displacement_cdf, vectors_per_plant, initial_sites_table, observation_times, duration, event_seeds, acquisition, inoculation, gamma, rho, sigma, omega, clearance, yield_healthy, yield_infected)

Numba-parallel low-level batch routine. Returns yields, final incidence, whole-field incidence, vector prevalence, SUSC incidence, RES incidence, final states and event counts.

run_ensemble
run_ensemble(*, N, cultivar, kernel, vectors_per_plant, initial_infectious, observation_times, duration, seed, acquisition, inoculation, gamma, rho, sigma, omega, clearance, yield_healthy, yield_infected, min_runs, max_runs, batch_size, final_incidence_mcse_tol, relative_yield_mcse_tol, fixed_sites=None, require_precision=True, store_infection_probability=False)

Adaptive publication wrapper. Runs batches until minimum effort plus incidence/yield precision conditions are met (unless precision is disabled), and returns run arrays plus mean/SD/MCSE summaries, runtime, kernel diagnostics and optional infection probability.

Use the right layerFor arbitrary coordinates, arbitrary composition or >2 varieties, use the core Field/MixtureDesign/CropMixSystem and simulate_mixture(). Use publication_backend when reproducing the manuscript’s square two-variety large-field analysis.
