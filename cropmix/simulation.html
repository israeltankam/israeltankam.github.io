Stochastic simulation

Run the spatial continuous-time Markov chain with Gillespie simulation.

Exact public signature#

simulate_mixture
simulate_mixture(design, system, scenario, *, n_runs=100, seed=12345, observation_times=None, transmission_draw=None, store_final_states=True)

Run replicated finite spatial SPT Gillespie trajectories. There is no engine or backend argument in the frozen 0.2.0 core source.

Arguments#

ArgumentBehaviour
designAny valid MixtureDesign using system varieties.
systemCropMixSystem; PT is rejected by the spatial engine.
scenarioDuration, vectors per plant, plant and vector introductions.
n_runsPositive number of Monte Carlo replicates.
seedMaster seed. Reuse across candidate designs for common-random-number comparisons.
observation_timesSorted non-empty 1-D times within [0,duration]. Default: 101 equally spaced points.
transmission_drawOptional coherent TransmissionDraw; otherwise system point values are used.
store_final_statesIf false, final state arrays and infection-probability map are discarded after summaries are computed.

State process#

Plants occupy S, L or I states. Virus-bearing vectors are tracked at each site by acquisition-origin variety. Events include plant inoculation, latent progression, roguing, vector acquisition, vector loss of infectivity, vector mortality/replacement and conservative non-local exchange.

Random introductions and seeds#

With Inoculum.random(k), distinct sites are redrawn independently for each replicate using a deterministic seed schedule. Event seeds are also replicate-specific. Reusing the same master seed across designs provides paired stochastic input streams for comparative design evaluation.

Example with explicit observation times and posterior draw#

import numpy as np

times = np.unique(np.r_[np.linspace(0,300,61), 120,180,240,300])
result = cm.simulate_mixture(
    design,
    system,
    scenario,
    n_runs=500,
    seed=20260824,
    observation_times=times,
    transmission_draw=draw,   # optional; omit to use point parameters
    store_final_states=True,
)

Performance boundary of the core simulator#

The geometry-general simulator prepares pairwise distances and a dense finite-field movement matrix. This is convenient and auditable for arbitrary moderate-sized fields, but memory grows quadratically with the number of planting sites. For large regular square lattices, cropmix.publication_backend provides a specialised structured representation when its binary-grid assumptions are appropriate.

Monte Carlo precision#

simulate_mixture() uses a fixed n_runs. The specialised publication_backend.run_ensemble() adds adaptive batching and checks Monte Carlo precision for final incidence and yield before stopping, subject to configured minimum and maximum run counts.

SD vs SE/MCSEStochastic standard deviation describes run-to-run variability. SimulationResult.yield_se is the Monte Carlo standard error of the mean yield. Do not report these as interchangeable uncertainty measures.
