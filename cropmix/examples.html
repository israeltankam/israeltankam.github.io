Examples

Self-contained scripts covering the main Cropmix workflows.

Each script can be downloaded and run independently. The core examples use small fields and illustrative parameters so they finish quickly. EpiPvr examples check the optional R installation before attempting inference.

Runnable scripts#

FileDemonstrates
quickstart.pyComplete core simulation
geometry_io.pyArbitrary coordinates and DataFrame import/export
multi_variety.pyThree-variety SPT simulation
vector_only.pyVector-borne introduction without infectious plants at t=0
meanfield_consistency.pySmall mean-field adequacy diagnostic
optimization.pyCount-preserving simulated annealing
generic_metrics.pyCoordinate-based pairwise mixing metrics
result_uncertainty.pySD, SE and trajectory exports
epipvr_bridge.pyAccess-period experiment and optional fit
branching_probability.pyOptional EpiPvr branching-process call
regular_grid_backend.pyStructured movement kernel for large regular grids

Recommended sequence#

  1. Run quickstart.py.
  2. Change the field representation with geometry_io.py.
  3. Try a mixture with more than two varieties using multi_variety.py.
  4. Inspect stochastic uncertainty with result_uncertainty.py.
  5. Use generic_metrics.py to quantify local mixing on arbitrary coordinates.
  6. Run optimization.py after you are comfortable interpreting Monte Carlo uncertainty.
  7. Use EpiPvr examples only when transmission inference from access-period experiments is part of the workflow.
Large regular gridsregular_grid_backend.py demonstrates the structured movement-kernel preparation used by the specialised binary square-grid backend. The geometry-general API remains the default for arbitrary fields.
