Suggested learning sequence

  1. Run quickstart.py.
  2. Change field and composition with geometry_io.py / multi_variety.py.
  3. Explore alternate infection sources.
  4. Inspect stochastic outputs before attempting optimisation.
  5. Use mean-field consistency only as an approximation diagnostic.
  6. Add EpiPvr only when you need upstream parameter inference.
  7. Use the publication backend only for the specific large square-grid workflow it implements.
