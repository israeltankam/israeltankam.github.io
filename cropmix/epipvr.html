EpiPvr integration

Infer transmission parameters from access-period experiments through the optional R bridge.

Bridge architecture#

Cropmix keeps the user workflow in Python while invoking an independently installed R/EpiPvr package through Rscript. Parameter inference can be SPT or PT; the full spatial Cropmix simulator remains SPT-only.

Access-period data#

AccessPeriodAssay
AccessPeriodAssay(duration, tested, infected)

One varying-access-period assay. All three sequences must have equal non-zero length; durations/tested are positive and 0 ≤ infected ≤ tested.

AccessPeriodAssay.to_dataframe
assay.to_dataframe()

Return EpiPvr-style columns T_vec, R_vec, I_vec.

AccessPeriodExperiment.spt
AccessPeriodExperiment.spt(*, acquisition, inoculation, fixed_inoculation_for_acquisition, fixed_acquisition_for_inoculation, vectors_per_plant)

Build an SPT experiment and its 2×2 fixed-duration matrix.

AccessPeriodExperiment.pt
AccessPeriodExperiment.pt(*, acquisition, latent, inoculation, fixed_when_acquisition_varies, fixed_when_latency_varies, fixed_when_inoculation_varies, vectors_per_plant)

Build a PT experiment with AAP/LAP/IAP assays and a 3×3 fixed-duration matrix.

AccessPeriodExperiment.write_bundle
experiment.write_bundle(directory)

Write AAP.csv, IAP.csv, optional LAP.csv, durations.csv and metadata.csv for the internal R bridge.

Fit configuration and backend#

EpiPvrFitOptions
EpiPvrFitOptions(survival_upper_days=40.0, d_num_pts_pd=1, warmup=1000, iterations=2000, chains=4, parallel=0, seed=123)

Validated R/Stan fit settings. Requires 0 ≤ warmup < iterations and positive chains.

EpiPvrBackend
EpiPvrBackend(rscript="Rscript")

Subprocess bridge object.

EpiPvrBackend.check_installation
backend.check_installation()

Return status dictionary with Rscript availability, EpiPvr availability/version and message.

EpiPvrBackend.require_installation
backend.require_installation()

Raise EpiPvrError if Rscript or EpiPvr is unavailable.

EpiPvrBackend.fit
backend.fit(experiment, *, options=None)

Serialize the experiment, call the bundled R fitting bridge, read posterior/summary/diagnostics/Bayesian R² and return EpiPvrFit.

EpiPvrFit#

EpiPvrFit.posterior
fit.posterior(*, unit="per_day")

Return a copy of joint posterior rows. Rate columns are multiplied by 24 for per-day output; per_hour leaves them unchanged.

EpiPvrFit.parameter_summary
fit.parameter_summary(*, unit="per_day")

Mean, median, sample SD, q05 and q95 for all *_rate columns.

EpiPvrFit.median_host_transmission
fit.median_host_transmission()

Construct HostTransmission from per-day posterior medians.

EpiPvrFit.median_pathogen_parameters
fit.median_pathogen_parameters()

Construct PathogenParameters from posterior medians, including PT latent progression when present.

EpiPvrFit.convergence_report
fit.convergence_report(*, max_rhat=1.01, min_ess_per_chain=100.0)

Combine R-hat, bulk ESS, divergences and maximum-tree-depth diagnostics into a usable flag and detail dictionary.

EpiPvrFit.require_usable
fit.require_usable(**kwargs)

Raise EpiPvrError when convergence_report() is not usable.

Branching-process epidemic probability#

LocalEpidemicParameters
LocalEpidemicParameters(dispersal_rate, roguing_rate, harvest_rate, vector_mortality_rate, plant_latent_progression_rate)

Non-negative local field rates (day⁻¹) passed to EpiPvr’s branching-process calculator.

EpiPvrBackend.epidemic_probability
backend.epidemic_probability(*, vectors_per_plant, virus_parameters_per_day, local_parameters, initial_interval=0.1)

Call the EpiPvr branching-process epidemic-probability routine. virus_parameters_per_day is a three-rate tuple expected by the bridge.

EpidemicProbabilityResult
EpidemicProbabilityResult(probabilities, vectors_per_plant)

Stores the complete probability vector.

EpidemicProbabilityResult.from_single_infectious_plant
result.from_single_infectious_plant

Convenience property for the first entry.

EpidemicProbabilityResult.from_single_infectious_vector
result.from_single_infectious_vector

Convenience property selecting the EpiPvr state corresponding to one infectious vector.

End-to-end SPT fit#

from cropmix.epipvr import AccessPeriodAssay, AccessPeriodExperiment, EpiPvrBackend

aap = AccessPeriodAssay((2,3,4,5), (30,30,30,30), (10,15,18,20))
iap = AccessPeriodAssay((.25,.5,.75,1.0), (30,30,30,30), (5,10,15,20))
exp = AccessPeriodExperiment.spt(
    acquisition=aap,
    inoculation=iap,
    fixed_inoculation_for_acquisition=6,
    fixed_acquisition_for_inoculation=4,
    vectors_per_plant=20,
)
backend = EpiPvrBackend()
backend.require_installation()
fit = backend.fit(exp)
fit.require_usable()
posterior = fit.posterior(unit="per_day")
Inference boundaryPT inference through the bridge is supported, but passing a PT CropMixSystem to simulate_mixture() raises UnsupportedModelError. PT spatial simulation would require an explicit exposed-vector compartment.
