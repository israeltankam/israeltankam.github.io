Spatial metrics

Describe planting arrangement quantitatively so simulated outcomes can be interpreted in terms of spatial structure rather than layout names alone.

A planting design can be described by measurable properties such as local heterospecific contact, aggregation, boundary density, fragmentation, patch size and second-order spatial structure. These descriptors provide a common numerical language for comparing arrangements and relating epidemic or yield outcomes to geometry.

Metric layers in Cropmix#

Cropmix provides two metric layers with different domains of validity.

LayerGeometryVarietiesPurpose
cropmix.metrics.pairwise_mixing_metricsAny finite 2-D coordinatesAny number of labelsLocal mixing within an explicit Euclidean radius.

Arbitrary-coordinate mixing#

pairwise_mixing_metrics
cropmix.metrics.pairwise_mixing_metrics(design, *, radius)

Two sites are neighbours when their Euclidean separation is greater than zero and no larger than radius. The function returns a pandas Series containing the radius, number of neighbour pairs, heterotypic-pair fraction and mean local heterospecific fraction.

from cropmix.metrics import pairwise_mixing_metrics

metrics = pairwise_mixing_metrics(design, radius=1.5)
print(metrics)

Using metrics to generalise arrangement results#

Named arrangements are useful experimental designs, but their names are not mechanistic explanations. Spatial metrics translate those designs into measurable structural properties. This allows a user to ask whether simulated incidence or yield is associated with local mixing, boundary density, aggregation, patch size or another descriptor across several arrangements.

A typical workflow is:

  1. generate or import a set of planting designs;
  2. compute the same descriptors for every design;
  3. simulate the outcome of interest under a common biological scenario;
  4. fit an interpretable model linking descriptors to outcomes;
  5. evaluate out-of-sample predictive performance and resampling stability before interpreting a metric or metric pair.
Match the metric to the geometryA spatial concept can be useful beyond binary square grids, but the numerical definition must be valid for the target geometry and number of varieties. Use the arbitrary-coordinate metric for general fields, or define an explicit extension before applying binary-grid descriptors outside their stated scope.

Exact equal-count binary grid generators#

The regular-grid module includes two utilities for constructing equal-count binary grids.

correlated_exact_grid
correlated_exact_grid(N, sigma, seed)

Create an exact equal-count binary N×N grid from a Gaussian-filtered random field.

generate_hni_target_ensemble
generate_hni_target_ensemble(*, N, n_targets=25, replicates=8, seed=20260824, tolerance=5e-4)

Create exact equal-count binary grids spanning the HNI mixing axis. N must be even. Returns a grid dictionary and a manifest dataframe.
