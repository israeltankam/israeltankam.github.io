Spatial metrics & generalisation

Generalise controlled 50:50 arrangement results into spatial concepts, while distinguishing the arbitrary-coordinate core metric from the binary square-grid publication metric library.

Two metric layers in Cropmix

The package contains one geometry-agnostic core metric function for arbitrary coordinates and a richer publication-specific binary-grid metric library. This distinction matters: the scientific interpretation can generalise beyond named arrangements, while some current numerical metric implementations are deliberately tied to the two-variety square-grid study.

General arbitrary-coordinate mixing

pairwise_mixing_metrics
cropmix.metrics.pairwise_mixing_metrics(design, *, radius)

Define neighbours by Euclidean distance ≤ radius on any Field. Returns a pandas Series with radius, number of neighbour pairs, heterotypic-pair fraction and mean local heterospecific fraction.

from cropmix.metrics import pairwise_mixing_metrics
m = pairwise_mixing_metrics(design, radius=1.5)
print(m)

Why the 12 publication metrics were introduced

The canonical 50:50 patterns are controlled experiments in arrangement. The metric layer converts those results into geometric interpretations—mixing, separation, boundaries, fragmentation, patch scale, overlap and second-order structure—so conclusions are not restricted to statements such as “checkerboard versus half-split”. Metric-outcome relationships can then be tested on broader exact-count ensembles.

Ensemble generators

correlated_exact_grid
correlated_exact_grid(N, sigma, seed)

Generate an exact 50:50 binary N×N grid by Gaussian-filtering random noise and thresholding exactly half the sites.

generate_hni_target_ensemble
generate_hni_target_ensemble(*, N, n_targets=25, replicates=8, seed=20260824, tolerance=5e-4)

Generate exact 50:50 binary grids spanning the HNI axis using label-only simulated annealing. N must be even. Returns (grids_dict, manifest_dataframe).

Metric-pair generalisation method

The manuscript analysis fits interpretable two-metric predictors to simulated outcomes, evaluates held-out predictive R² and bootstrap rank stability, and ranks pairs separately by outcome/scenario. A pair with non-positive out-of-sample R² should not be declared predictive merely because it is stable.

Scope of generalisationThe interpretive framework generalises the 50:50 canonical results. The current 12-metric implementation in publication_backend is binary-square-grid code; applying it to arbitrary geometry or >2 varieties requires a corresponding general metric implementation rather than pretending the binary formulas are already universal.
