Reproducibility & QA

Seeds, environment checks, testing and release practices for repeatable analyses.

Freeze the full scientific state#

Archive package version, Python/platform/library versions, field coordinates, design assignment, biological parameters, scenario, movement scale, seeds, observation times and all analysis-level Monte Carlo stopping rules.

Seed semantics#

Random plant introductions and epidemic events are stochastic within a reproducible master-seed schedule. Reusing one seed across competing designs is deliberate common-random-number pairing, not a request for identical trajectories.

Required numerical invariants#

  • Field coordinates are finite and unique.
  • Design labels exactly match field size and all labels are present in CropMixSystem.
  • Dense prepared kernel has row sums ≈1, symmetry ≈0 error and zero diagonal.
  • Vector-count invariant holds during every compiled simulation.
  • Exact cultivar counts are checked before and after optimisation swaps.
  • SPT/PT boundary is enforced rather than silently approximated.
  • Stochastic SD and MCSE are labelled separately.
  • Joint EpiPvr rows stay joint through propagation.

Tests run against the source snapshot used here#

This documentation was audited against the exact Cropmix 0.2.0 source embedded in Final_robust_complete_revised_2026-08-24.zip. Running its full extracted test directory in this session gave:

PYTHONPATH=src NUMBA_NUM_THREADS=2 pytest -q
# 17 passed, 1 deprecation warning (calibrate_kernel alias)

The website additionally checks that every documented package-root export and EpiPvr export appears in the API inventory, that internal HTML links resolve, and that the final ZIP passes an archive integrity test.

Release commands#

python -m compileall -q src
pytest -q
ruff check src tests
python -m build
python -m twine check dist/*
