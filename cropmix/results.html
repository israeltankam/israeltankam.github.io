Results & stochastic uncertainty

Use every SimulationResult field, property and plotting/export method, including the corrected pointwise stochastic SD envelopes.

SimulationResult data fields

Cropmix retains expensive run-level stochastic information so uncertainty can be recomputed without rerunning the epidemic.

FieldShape / meaning
design, scenarioInput objects.
timeObservation times.
yield_runsOne realised yield per run.
final_incidence_runsOne final infectious fraction per run.
incidence_runsRun × time whole-field incidence.
vector_prevalence_runsRun × time virus-bearing-vector prevalence.
incidence_by_variety_runsName → run × time within-variety incidence.
final_statesRun × site final state codes, or None.
infection_probabilitySite-wise P(infectious at T), or None when final states were not stored.
kernel_scale, mean_step_distanceMovement provenance.
seed, yield_unitReproducibility and units.

Methods

SimulationResult.summary
result.summary()

One-row dataframe containing n_runs, mean/SD/SE yield, mean/SD final incidence, kernel scale and mean step distance.

SimulationResult.trajectory_dataframe
result.trajectory_dataframe()

Tidy dataframe with time, means, SDs and clipped ±1 SD lower/upper envelopes for field incidence, vector prevalence and each variety.

SimulationResult.plot_incidence
result.plot_incidence(ax=None, *, by_variety=False, show_sd=True, sd_multiplier=1.0, envelope_alpha=0.2)

Plot field incidence and optionally cultivar trajectories. SD envelopes are shown by default; requires viz extra.

SimulationResult.plot_vector_prevalence
result.plot_vector_prevalence(ax=None, *, show_sd=True, sd_multiplier=1.0, envelope_alpha=0.2)

Plot mean vector prevalence with optional SD band.

SimulationResult.plot_final_infection_probability
result.plot_final_infection_probability(ax=None, *, marker_size=100)

Scatter field coordinates coloured by site-level final infection probability. Requires final states and viz extra.

Export stochastic trajectories

result.summary().to_csv("summary.csv", index=False)
result.trajectory_dataframe().to_csv("trajectories.csv", index=False)

# Raw arrays remain available for quantiles, paired comparisons, etc.
q05, q50, q95 = np.quantile(result.final_incidence_runs, [0.05,0.5,0.95])
Do not discard raw runsThe corrected package exposes SDs and ±SD envelopes, but the raw run arrays remain the primary information. Preserve them when storage permits.
