Scenarios & inoculum

Specify simulation horizon, vector burden and plant/vector introductions.

Scenario#

Scenario
Scenario(duration=300.0, vectors_per_plant=10, inoculum=Inoculum(), vector_inoculum=VectorInoculum())

Field-level conditions. Duration and vectors per plant must be positive. The default is one random infectious plant and virus-free vectors.

A disease-free control with zero infected plants and zero infectious vectors is explicitly valid in the 0.2.0 source.

Plant inoculum#

Inoculum
Inoculum(count=1, sites=None)

If sites=None, choose count distinct random sites independently for each replicate. Explicit sites fix the introduction location.

Inoculum.random
Inoculum.random(count=1)

Random plant introduction.

Inoculum.fixed
Inoculum.fixed(sites)

Fixed, unique integer site indices.

Inoculum.none
Inoculum.none()

Zero infectious plants.

Vector inoculum#

VectorInoculum
VectorInoculum(infectious_fraction=0.0, origin_weights=None)

Initial probability that each individual vector is virus-bearing. infectious_fraction lies in [0,1]. Optional non-negative origin_weights are normalised across system varieties; when omitted, planted variety frequencies are used for provenance.

VectorInoculum.none
VectorInoculum.none()

All vectors virus-free at time zero.

Examples#

# One random infectious plant; virus-free vectors
s1 = cm.Scenario(300, 10, cm.Inoculum.random(1), cm.VectorInoculum.none())

# Five random infectious plants
s2 = cm.Scenario(300, 5, cm.Inoculum.random(5), cm.VectorInoculum.none())

# Fixed plant introductions
s3 = cm.Scenario(120, 4, cm.Inoculum.fixed([12, 50, 87]), cm.VectorInoculum.none())

# Vector-only introduction: 2% of vectors initially virus-bearing
s4 = cm.Scenario(60, 4, cm.Inoculum.none(), cm.VectorInoculum(infectious_fraction=0.02))

# Combined sources
s5 = cm.Scenario(180, 8, cm.Inoculum.random(2), cm.VectorInoculum(infectious_fraction=0.05))

# Disease-free control
control = cm.Scenario(30, 3, cm.Inoculum.none(), cm.VectorInoculum.none())
Random means random per replicateFor random inoculum, the simulator uses a reproducible but replicate-specific draw of distinct site indices. Reusing the master seed recreates the sequence; it does not force the same plant to be infected in every run.
