Performance & HPC

Choose between the general dense core and the specialised square-lattice publication backend, and run long Monte Carlo campaigns with precision checks and restartable cluster execution.

Core complexity

The geometry-general simulate_mixture() calls ExponentialKernel.prepare(field), which builds pairwise distances, movement probabilities and a CDF. Memory therefore scales quadratically with the number of sites. The Numba event loop is fast after compilation, but it does not remove dense-kernel memory.

Choose the computational path by geometry

ProblemRecommended path
Irregular / surveyed / polygon / moderate fieldCore simulate_mixture().
Small regular grid and software testsCore dense simulator; easy to audit against theory.
100×100 manuscript-style two-variety square latticepublication_backend.prepare_structured_kernel() + run_ensemble(), or the supplied Cluster_100x100 runner.

First-call compilation

The first simulation in a Python process pays Numba compilation cost. Subsequent calls reuse compiled functions when possible. Time software benchmarking only after a warm-up call if you want steady-state performance.

Adaptive Monte Carlo

The publication backend accumulates batches from min_runs to max_runs, checks final-incidence MCSE and yield MCSE relative to the mean, and can retain site infection probabilities. This is preferable to picking a nominal run count without precision auditing.

Cluster execution

The delivered manuscript bundle contains a self-contained Cluster_100x100 workflow with local source, requirements, a verification script, shell runner and generic SLURM submission file. The analysis caches completed scenarios/designs so an interrupted job can resume rather than repeating completed work.

# Generic SLURM pattern from the delivered cluster workflow
sbatch slurm_100x100.sbatch
squeue -u "$USER"
tail -f cropmix_100x100_<jobid>.log
Publication backend is specialisedIts efficiency comes partly from assuming a square binary two-variety lattice. It is not a drop-in replacement for arbitrary geometry or arbitrary numbers of varieties.
