GitHub Pages deployment

Publish this static documentation under israeltankam.github.io/cropmix/.

Target structure#

You said the documentation will live in a subfolder of your personal GitHub Pages repository. This package is built for that exact structure:

israeltankam.github.io/
├── ... your existing personal site ...
└── cropmix/
    ├── index.html
    ├── getting-started.html
    ├── api.html
    ├── ...
    ├── assets/
    ├── examples/
    ├── sitemap.xml
    └── .nojekyll

All internal links and assets are relative, so the site works under https://israeltankam.github.io/cropmix/ without a custom base-path configuration.

Deploy by copying the folder#

Unzip the website bundle.
Copy the contained cropmix/ folder into the root of your israeltankam.github.io repository.
Commit and push to the branch from which your personal site is served.
Open https://israeltankam.github.io/cropmix/ and test navigation, search and code-copy buttons.

Example Git commands#

cd path/to/israeltankam.github.io
cp -R path/to/unzipped/cropmix ./cropmix
git add cropmix
git commit -m "Add Cropmix documentation"
git push

Why .nojekyll is included#

The site is plain static HTML/CSS/JavaScript and does not need Jekyll processing. The marker prevents Jekyll-specific filtering from interfering with static assets.

Updating the documentation#

Replace the folder contents with the new build, preserve relative paths, then commit. If the Python package version changes, update the version badge, API compatibility notes and examples before publishing.

Optional source repository link#

The current package metadata guide uses https://github.com/israeltankam/cropmix as the source repository. The website's “Source” button points there. If you choose a different repository, edit that URL in every HTML page or regenerate the site.
