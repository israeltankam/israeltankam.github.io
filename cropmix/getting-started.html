Getting started

Install Cropmix 0.2.0, run a complete stochastic simulation, and understand the boundary between the core dense API and the publication-scale backend.

Installation

Cropmix 0.2.0 requires Python >=3.10. The package metadata declares support for Python 3.10–3.13 and depends on NumPy, pandas, SciPy and Numba. Matplotlib is optional and is installed through the viz extra.

python -m venv cropmix-env
source cropmix-env/bin/activate        # Windows: cropmix-env\Scripts\activate
python -m pip install --upgrade pip
python -m pip install cropmix-0.2.0-py3-none-any.whl
python -c "import cropmix; print(cropmix.__version__)"

When the package is published to PyPI, the normal installation is python -m pip install cropmix. Optional extras:

python -m pip install "cropmix[viz]"
python -m pip install "cropmix[dev,viz,docs]"

Command-line checks

cropmix --version
cropmix doctor

doctor reports the Cropmix/Python environment and, if present, the Rscript and EpiPvr installation used by the optional bridge.

60-second simulation

import cropmix as cm

field = cm.Field.rectangular(rows=10, columns=10, spacing=1.0)

susc = cm.Variety(
    name="SUSC",
    transmission=cm.HostTransmission(15.31, 1.34),
    plant=cm.PlantParameters(1/30, roguing_rate=0.0),
    yield_model=cm.YieldParameters(31.0, 3.1, unit="t/ha"),
)
res = cm.Variety(
    name="RES",
    transmission=cm.HostTransmission(4.84, 0.42),
    plant=cm.PlantParameters(1/30),
    yield_model=cm.YieldParameters(25.0, 2.1, unit="t/ha"),
)

system = cm.CropMixSystem(
    varieties=(susc, res),
    vector=cm.VectorParameters(mortality_rate=0.19, dispersal_rate=0.45),
    pathogen=cm.PathogenParameters(vector_clearance_rate=19.37, transmission_mode="SPT"),
    kernel=cm.ExponentialKernel(scale=2.625),
)

design = cm.MixtureDesign.random(
    field,
    counts={"SUSC": 50, "RES": 50},
    seed=1,
)

scenario = cm.Scenario(
    duration=300,
    vectors_per_plant=10,
    inoculum=cm.Inoculum.random(1),
    vector_inoculum=cm.VectorInoculum.none(),
)

result = cm.simulate_mixture(
    design,
    system,
    scenario,
    n_runs=20,
    seed=42,
)
print(result.summary())
Important for large fieldsThe installed simulate_mixture() function prepares a dense finite-field movement matrix. The project’s 100×100 publication campaign therefore uses the specialised structured functions in cropmix.publication_backend (and the supplied cluster runner), which implement the same two-variety publication CTMC without materialising the dense 10,000×10,000 matrix.
