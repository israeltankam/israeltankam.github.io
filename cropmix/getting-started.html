Getting started

Getting started

Install Cropmix, define a field and two varieties, run a stochastic epidemic and inspect the result.

Requirements#

Cropmix 0.2.0 requires Python 3.10 or newer and depends on NumPy, pandas, SciPy and Numba. Plotting is optional and is installed with the viz extra.

python -m venv cropmix-env
source cropmix-env/bin/activate        # Windows: cropmix-env\Scripts\activate
python -m pip install --upgrade pip
python -m pip install cropmix

If you are installing a local wheel instead of a registry release:

python -m pip install ./dist/cropmix-0.2.0-py3-none-any.whl

Optional extras#

python -m pip install "cropmix[viz]"
python -m pip install "cropmix[dev,viz,docs]"

Check the installation#

python -c "import cropmix; print(cropmix.__version__)"
cropmix --version
cropmix doctor

cropmix doctor reports the Python environment and also checks for Rscript and EpiPvr when you plan to use the optional inference bridge.

A complete minimal example#

This example uses illustrative rate values. The units of all rates are per day; yields use an arbitrary but internally consistent unit.

import cropmix as cm

# 1. Planting coordinates
field = cm.Field.rectangular(rows=6, columns=6, spacing=1.0)

# 2. Host varieties
variety_a = cm.Variety(
    name="A",
    transmission=cm.HostTransmission(
        acquisition_rate=0.80,
        inoculation_rate=0.25,
    ),
    plant=cm.PlantParameters(
        latent_progression_rate=1 / 18,
        roguing_rate=0.0,
    ),
    yield_model=cm.YieldParameters(
        healthy=1.0,
        infected=0.45,
        unit="relative yield",
    ),
)

variety_b = cm.Variety(
    name="B",
    transmission=cm.HostTransmission(
        acquisition_rate=0.35,
        inoculation_rate=0.10,
    ),
    plant=cm.PlantParameters(latent_progression_rate=1 / 18),
    yield_model=cm.YieldParameters(
        healthy=0.90,
        infected=0.65,
        unit="relative yield",
    ),
)

# 3. Vector, pathogen and movement model
system = cm.CropMixSystem(
    varieties=(variety_a, variety_b),
    vector=cm.VectorParameters(
        mortality_rate=0.15,
        dispersal_rate=0.40,
    ),
    pathogen=cm.PathogenParameters(
        vector_clearance_rate=1.5,
        transmission_mode="SPT",
    ),
    kernel=cm.ExponentialKernel(scale=1.5),
)

# 4. Exact planting composition
#    36 sites = 18 plants of A + 18 plants of B
design = cm.MixtureDesign.random(
    field,
    counts={"A": 18, "B": 18},
    seed=7,
)

# 5. Epidemic conditions
scenario = cm.Scenario(
    duration=120,
    vectors_per_plant=5,
    inoculum=cm.Inoculum.random(count=1),
    vector_inoculum=cm.VectorInoculum.none(),
)

# 6. Monte Carlo simulation
result = cm.simulate_mixture(
    design,
    system,
    scenario,
    n_runs=50,
    seed=42,
)

print(result.summary())
Random introductions are replicate-specificWith Inoculum.random(count=1), the initially infectious plant is sampled independently for each stochastic replicate. The global simulation seed makes the experiment reproducible.

Inspect the result#

print(result.mean_yield)
print(result.yield_sd)                 # run-to-run variability
print(result.yield_se)                 # Monte Carlo SE of the mean
print(result.mean_final_incidence)

trajectory = result.trajectory_dataframe()
print(trajectory.head())

With plotting support installed:

result.plot_incidence(by_variety=True)
result.plot_vector_prevalence()
result.plot_final_infection_probability()
