Worked example: cassava brown streak disease

A self-contained applied example using cassava brown streak disease (CBSD) to demonstrate a complete Cropmix workflow.

CBSD is a whitefly-transmitted viral disease of cassava. This example illustrates how published biological rates, cultivar-specific yield effects, a spatial movement kernel and a defined epidemic introduction can be assembled into Cropmix objects. The numerical values belong to this worked example; users should provide parameters appropriate to their own crop–pathogen–vector system.

Purpose#

This example demonstrates how to construct a two-variety cassava system, define a spatial field and epidemic scenario, run stochastic simulations, and analyse arrangement effects. The same Cropmix objects can be used for other crop–pathogen–vector systems with parameters appropriate to the application.

Core biological objects#

import cropmix as cm

SUSC = cm.Variety(
    "SUSC",
    cm.HostTransmission(15.31, 1.34),
    cm.PlantParameters(1/30, 0.0),
    cm.YieldParameters(31.0, 3.1, "t/ha"),
)
RES = cm.Variety(
    "RES",
    cm.HostTransmission(4.84, 0.42),
    cm.PlantParameters(1/30, 0.0),
    cm.YieldParameters(25.0, 2.1, "t/ha"),
)
SYSTEM = cm.CropMixSystem(
    (SUSC, RES),
    cm.VectorParameters(0.19, 0.45),
    cm.PathogenParameters(19.37, "SPT"),
    cm.ExponentialKernel(2.625),
)

Movement and harvest choices#

The primary Cropmix exponential scale is a=2.625 m, translating a published two-dimensional exponential mean distance of 5.25 m; the biological sensitivity interval is 0.5–5.75 m. The primary season is 300 days and the prespecified harvest-time sensitivity is 120, 180, 240, 300 and 360 days.

Example 100×100 field#

FIELD = cm.Field.rectangular(100,100,spacing=1.0)
DESIGN = cm.MixtureDesign.random(FIELD, {"SUSC":5000, "RES":5000}, seed=20260824)
SCENARIO = cm.Scenario(
    duration=300,
    vectors_per_plant=10,
    inoculum=cm.Inoculum.random(1),
    vector_inoculum=cm.VectorInoculum.none(),
)

For large regular grids, the specialised structured backend is computationally preferable to the geometry-general dense movement matrix when its binary square-lattice assumptions match the design.

Example scenario matrix#

An analysis can compare several vector burdens and several initial infectious-plant counts. Labels such as LvLi or HvHi are optional user-defined experiment labels and are not part of the Cropmix API.

Spatial descriptors#

Spatial descriptors express arrangement effects through measurable properties such as local mixing, boundaries, aggregation, patch size and fragmentation, rather than relying only on the names of planting layouts.

Adapting the example#

  • Choose any supported field representation: rectangle, mask, polygon or directly supplied coordinates.
  • Specify the required variety counts explicitly; mixture composition is user-defined.
  • Declare every variety used by the SPT system in CropMixSystem.
  • Choose plant and vector introductions independently through Inoculum and VectorInoculum.
  • Optimise any exact count vector with a built-in or user-defined scalar objective.
Parameter portability The movement scale, transmission rates, vector burden and yield values in this example are application-specific inputs. Use independently justified parameters for a different crop–pathogen–vector system.
