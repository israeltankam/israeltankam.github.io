Cropmix

Spatial epidemiology and planting-design tools for crop varietal mixtures and vector-borne plant viruses.

Spatial CTMCGillespie SSAArbitrary 2-D fieldsSPT virusesEpiPvr bridge

Cropmix is reusable scientific software for asking a practical spatial question: given a field, a set of crop varieties and a vector-borne pathogen, where should each variety be planted and what epidemic/yield consequences should we expect?

The package separates field geometry, cultivar assignment, biological parameters, epidemic scenario, vector movement, stochastic simulation and downstream analysis. The cassava/CBSD study is one application; the package itself is not restricted to cassava, 50:50 mixtures, square fields, two varieties or one inoculum site.

What Cropmix can do

Represent real planting layouts

Use rectangular grids, arbitrary surveyed coordinates, masks with holes, or polygon-defined planting domains. A design maps exactly one cultivar label to every planting position.

Run finite stochastic epidemics

The spatial process is a continuous-time Markov chain. Cropmix uses an exact Gillespie-style event simulation with Numba acceleration and retains replicate-level outcomes.

Model non-local vector movement

Movement follows an exponential distance kernel and finite-field symmetric balancing. Reciprocal exchange preserves exactly m vectors at every planting position.

Use multiple cultivars

The SPT engine supports more than two cultivars and tracks viruliferous-vector provenance by acquisition-origin cultivar. The paper's two-cultivar design is a case-study restriction.

Handle flexible introductions

Start with zero, random or fixed infectious plants, optional virus-bearing vectors, or combined plant/vector introductions. Random plant sites can change independently between replicates while remaining reproducible under a seed.

Move from simulation to decisions

Compute spatial descriptors, compare to a mean-field reference, propagate EpiPvr parameters and search fixed-composition design spaces with count-preserving simulated annealing.

Important scientific distinctionThe biological movement scale is not estimated by forcing the spatial model to match the mean-field model. assess_mean_field_consistency() asks when a non-spatial approximation becomes adequate; it is a model-adequacy diagnostic. The legacy name calibrate_kernel() is retained only as a deprecated compatibility alias.
