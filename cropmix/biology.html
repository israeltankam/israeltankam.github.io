Biological parameters

Define host, vector and pathogen parameters and propagate coherent transmission draws.

Biological parameter objects#

All core parameter containers are validated dataclasses. Rates are non-negative; the documented scientific convention is days.

HostTransmission
HostTransmission(acquisition_rate, inoculation_rate)

Host-dependent acquisition rate (day⁻¹) and per-virus-bearing-vector inoculation rate (vector⁻¹ day⁻¹).

PlantParameters
PlantParameters(latent_progression_rate, roguing_rate=0.0)

Plant latent progression and optional roguing/removal rate.

YieldParameters
YieldParameters(healthy, infected, unit="t/ha")

Healthy and infected yields in one user-chosen non-empty unit.

Variety
Variety(name, transmission, plant, yield_model)

Named host variety/phenotype combining transmission, plant and yield objects.

Variety.with_transmission
variety.with_transmission(transmission)

Return an immutable copy with replaced transmission rates.

VectorParameters
VectorParameters(mortality_rate, dispersal_rate)

Vector mortality/replacement and tagged-vector movement rates.

PathogenParameters
PathogenParameters(vector_clearance_rate, transmission_mode="SPT", vector_latent_progression_rate=None)

Shared vector infectivity loss plus SPT/PT mode. PT requires a positive vector latent progression rate; the current spatial simulator still rejects PT.

TransmissionDraw
TransmissionDraw(acquisition_rates, inoculation_rates, vector_clearance_rate, vector_latent_progression_rate=None)

One coherent parameter draw keyed by variety. Acquisition and inoculation dictionaries must contain exactly the same names; use this to preserve posterior dependence.

CropMixSystem#

CropMixSystem
CropMixSystem(varieties, vector, pathogen, kernel=ExponentialKernel())

Combine one or more unique varieties, vector parameters, pathogen parameters and movement kernel. All varieties must share the same yield unit.

CropMixSystem.from_iterable
CropMixSystem.from_iterable(varieties, *, vector, pathogen, kernel=None)

Build a system from any iterable of varieties. If kernel is omitted, ExponentialKernel() is used.

CropMixSystem.variety
system.variety(name)

Return a named Variety; raises KeyError if absent.

CropMixSystem.validate_design
system.validate_design(design)

Ensure every label in a design is represented in the system.

CropMixSystem.ensure_spatial_supported
system.ensure_spatial_supported()

Raise UnsupportedModelError for non-SPT systems.

CropMixSystem.with_kernel_scale
system.with_kernel_scale(scale)

Return a copy using the same biology and a new exponential-kernel scale.

CropMixSystem.point_transmission_draw
system.point_transmission_draw()

Convert current point parameters into a coherent TransmissionDraw.

Parameter uncertainty#

draw = cm.TransmissionDraw(
    acquisition_rates={"A":0.20, "B":0.10},
    inoculation_rates={"A":0.08, "B":0.04},
    vector_clearance_rate=0.5,
)
result = cm.simulate_mixture(
    design, system, scenario,
    transmission_draw=draw,
    n_runs=200,
    seed=90,
)
Joint rows matterWhen a TransmissionDraw comes from EpiPvr, preserve each joint posterior row. Do not independently shuffle acquisition, inoculation and clearance marginals.
