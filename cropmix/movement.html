Vector movement

Configure the exponential movement kernel and inspect finite-field balancing diagnostics.

Core exponential kernel#

ExponentialKernel
ExponentialKernel(scale=1.0, balance_tolerance=1e-11, balance_max_iter=20000)

Raw weights follow exp(-d/scale). Scale, balancing tolerance and iteration limit must be positive.

ExponentialKernel.with_scale
kernel.with_scale(scale)

Return an immutable copy with a new positive scale.

ExponentialKernel.prepare
kernel.prepare(field)

Compute the full dense distance matrix, raw weights, symmetric balanced movement probabilities, CDF and finite-field diagnostics.

Wij = exp(−dij/a), Wii=0

The prepared probabilities are symmetric and row-stochastic. In the conservative vector-exchange generator, reciprocal exchanges preserve exactly m vectors at each site.

PreparedKernel#

PreparedKernel
PreparedKernel(scale, probabilities, distances, cdf, mean_step_distance, max_row_error, max_symmetry_error)

Dense finite-field movement object returned by ExponentialKernel.prepare(). Arrays are made read-only.

FieldMeaning
probabilitiesBalanced row-stochastic symmetric matrix P.
distancesPairwise Euclidean distance matrix.
cdfRow-wise destination CDF.
mean_step_distanceMean movement distance after finite-field balancing.
max_row_errorMaximum |row sum − 1|.
max_symmetry_errorMaximum |P − Pᵀ|.

Low-level balancing helper#

symmetric_sinkhorn
cropmix.kernels.symmetric_sinkhorn(weights, *, tol=1e-11, max_iter=20000)

Balance a symmetric non-negative square matrix to a reciprocal doubly/row-stochastic matrix. This is a submodule helper, not exported from the package root.

Dense kernel audit#

import numpy as np
field = cm.Field.rectangular(8, 8)
k = cm.ExponentialKernel(2.625).prepare(field)
P = k.probabilities
assert np.max(np.abs(P.sum(axis=1)-1)) < 1e-10
assert np.max(np.abs(P-P.T)) < 1e-10
assert np.max(np.abs(np.diag(P))) < 1e-12
print(k.mean_step_distance, k.max_row_error, k.max_symmetry_error)

Structured kernel for large square grids#

The geometry-general simulator uses a dense PreparedKernel. For large regular square lattices, cropmix.publication_backend provides a structured representation that avoids materialising the full pairwise movement matrix.

publication_backend.prepare_structured_kernel
prepare_structured_kernel(N, scale, *, tolerance=1e-8, max_iter=5000, damping=0.5)

Prepare symmetric finite-field balancing on an open N×N unit-spaced lattice using FFT convolution and return a StructuredKernel.

from cropmix.publication_backend import prepare_structured_kernel
structured = prepare_structured_kernel(N=100, scale=2.625)
print(structured.mean_step_distance, structured.max_row_error, structured.iterations)
Dense and structured kernels are different representations PreparedKernel is used by the arbitrary-coordinate core simulator. StructuredKernel is specialised to large square lattices and should be used through the regular-grid backend.

Biological interpretation of scale#

The movement scale must come from independent biological evidence. Mean-field consistency asks when a non-spatial approximation becomes adequate; it does not estimate vector dispersal biology.
