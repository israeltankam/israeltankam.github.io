# Psychotherapy Exam Lab

A fully static, dependency-free study website for GitHub Pages.

## Deploy on GitHub Pages

1. Create a new GitHub repository (for example `psychotherapy-exam-lab`).
2. Upload **all files and folders from this directory to the repository root**. Keep the `exams/` folder intact.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will display the public Pages URL after deployment.

No npm, build step, database, analytics, CDN, or server is required.

## Included study features

- 13 structured course/revision modules
- 100+ concept cards
- Flashcards with local “got it / again” progress
- Randomized MCQ + True/False quiz engine
- Learning mode and exam mode
- Local weak-area/error tracking
- 27 clinical simulation cases with marking points
- 10 complete practice exam PDFs + 10 detailed solution PDFs
- Search across modules, concepts and cases
- Dark/light mode
- Responsive mobile layout
- Progress stored only in the browser via `localStorage`

## Source fidelity

The site is grounded in the recovered psychotherapy course/source-title map and the supplied 2025 VTI-AEDA exam structure. The source-title map is retained in `course-source-map.txt` and the fuller methodology note in `SOURCE_AND_COVERAGE_NOTE.txt`.

The site is a **revision synthesis, not a verbatim transcript and not an official VTI-AEDA answer key**. Explanatory lessons and mnemonics organize and teach the source-supported topics in exam-ready form.
