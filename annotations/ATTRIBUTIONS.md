# Sources et licences des données

Les cas de recherche de ce site sont des extraits adaptés de deux jeux de données publics.

## HotpotQA

HotpotQA a été créé par Zhilin Yang, Peng Qi, Saizheng Zhang, Yoshua Bengio, William W. Cohen et Ruslan Salakhutdinov. Le jeu de données est distribué sous licence **CC BY-SA 4.0**. Les cas utilisés ici sont présentés en anglais et dans une traduction française préparée pour cette étude.

Projet : https://hotpotqa.github.io/
Licence : https://creativecommons.org/licenses/by-sa/4.0/

## SciFact

SciFact a été créé pour l'évaluation de la vérification d'affirmations scientifiques. Les affirmations et annotations de preuves sont distribuées sous **CC BY 4.0**. Les résumés scientifiques proviennent du corpus S2ORC et sont distribués sous **ODC-By 1.0**. Les traductions françaises affichées ici ont été préparées pour cette étude ; le texte anglais original reste accessible.

Projet : https://github.com/allenai/scifact
Licence SciFact : https://github.com/allenai/scifact/blob/master/LICENSE.md

Les traductions ne remplacent pas les textes sources. En cas de nuance scientifique importante, l'annotateur peut afficher l'original anglais.
