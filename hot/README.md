# Hot Escalation — version statique GitHub Pages

Cette version reproduit l'application Streamlit entièrement dans le navigateur (HTML/CSS/JavaScript), sans backend Python.

## Publication sur GitHub Pages

1. Copiez **tout le contenu de ce dossier** à la racine du dépôt GitHub à publier.
2. Dans GitHub : **Settings → Pages**.
3. Dans **Build and deployment**, choisissez **Deploy from a branch**.
4. Sélectionnez la branche (par exemple `main`) et le dossier `/ (root)`, puis enregistrez.

Le site utilise uniquement des fichiers statiques. Le fichier `data/gages.js` contient les 231 gages de l'application originale et `assets/sounds/success.mp3` conserve le son du minuteur.
